# 架构

智能体原生会话 → 忆桥 Bridge → 标准来源事件与可靠outbox → 知枢 Core → 有证据的事实/版本/冲突/索引 → 统一召回 → 忆桥 → 宿主。

Bridge不另做语义提炼，Core是唯一提炼中心。宿主可信绑定决定workspace/project/actor，历史引用不是新用户指令。身份与能力定义仍由宿主管理；共享的是工作事实。技能可登记来源，不由中央记忆分发执行。

原文、时间精度、来源血缘与事实分开；更正优先于迟到异步提炼；完成自述不自动升级为已核验完成。读到的历史配置不冒充当前实测。秘密引用在宿主可解析，值不进记忆/日志/模型输入；正文脱敏和待处理状态必须诚实。

SQLite本地，向量可重建。ACK需真实收据，补交不重提炼。首次冷历史全文保护，在KW暂缓队列保持pending可见。保留/召回/导入/维护不伪造新业务时间，不以再次提及自动续期。原30/180/365保留规则继续按各层契约执行。

语义模型经现有网关调用；CPU BGE独立环境，1024维/512token，模型资源不存Git。无需OpenViking、Mem0或其他数据库服务。
